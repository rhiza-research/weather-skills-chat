# Weather Skills Chat

Weather Skills Chat is a chat app for weather and climate analysis, built on Open WebUI 0.6.5. In the app it is named "Weather Skills".

The model in a chat can run weather skills: small programs that fetch forecasts and observations, transform the data, and draw maps and charts. Each chat keeps its own files, so a user can look at, download, and email what the skills produced. Teams share chats, skills, secrets, and saved instructions inside organizations, and admins set monthly spending limits. Chats can also run on a schedule.

These pages describe what Weather Skills Chat adds or changes in Open WebUI, for the people who use the app and the admins who run it. For the Open WebUI features the app keeps, see the [Open WebUI documentation](https://docs.openwebui.com/).

Every page is listed in the sidebar.
