# Welcome Tour

The first time a user signs in and reaches the new chat page, a five-step tour points at the organization, the message box, the file-reading switch, Artifacts, and scheduled tasks. The message box is filled with an example request for the user to edit and send; it is not sent for them. Steps whose part is not on screen, such as the sidebar on a small screen, are skipped.

Closing or finishing the tour marks it as seen on the user's account, so it does not start again in any browser. **Take the tour** in the **?** menu runs it again.
